## 1. 项目概述

AgentScope 是由阿里巴巴通义实验室 SysML 团队开发的一款**企业级开箱即用的多智能体框架**。其核心设计理念是提供灵活的核心抽象以适配不断进化的模型能力，并原生支持模型微调。

### 核心特性

- **灵活的智能体抽象** — 基于 ReAct 模式的智能体，支持工具调用、结构化输出、长期记忆、RAG 知识检索、计划管理等
- **多模型支持** — 内置 OpenAI、DashScope（阿里云）、Anthropic、Gemini、Ollama、DeepSeek、Trinity 等模型适配
- **丰富的工具生态** — 内置代码执行、文件操作、多模态工具（文生图/图生文/文生音频）、MCP 协议集成
- **RAG 检索增强** — 完整的文档读取、向量存储、知识库检索链路
- **多智能体协作** — 顺序/扇出流水线、消息广播中心（MsgHub）、聊天室（ChatRoom）
- **A2A 协议** — 支持智能体间通信协议，含 Nacos 服务发现
- **实时交互** — 实时语音模型 + RealtimeAgent + ChatRoom，支持语音对话
- **可观测性** — OpenTelemetry 链路追踪、AgentScope Studio 可视化
- **会话持久化** — JSON / Redis / TableStore 会话存储
- **模型微调** — 内置 Tuner 模块，支持 DSPy 和 Trinity-RFT
- **评估框架** — 内置 Benchmark 和 Evaluator 抽象

## 3. 核心模块详解

### 3.1 agent — 智能体模块

| 类 | 说明 |
|---|---|
| `AgentBase` | 所有智能体的基类，继承自 `StateModule`，定义 `reply()`/`observe()`/`print()` 核心接口，支持 6 类 Hook |
| `ReActAgentBase` | ReAct 模式智能体基类，继承 `AgentBase` |
| `ReActAgent` | 核心智能体实现，支持工具调用、RAG、计划、长期记忆、记忆压缩、结构化输出、TTS、并行工具调用、Meta Tool |
| `UserAgent` | 用户交互智能体，支持终端输入和 Studio UI 输入 |
| `A2AAgent` | A2A 协议智能体，支持智能体间通信 |
| `RealtimeAgent` | 实时语音交互智能体 |

**AgentBase Hook 机制**: 支持 `pre_reply`、`post_reply`、`pre_print`、`post_print`、`pre_observe`、`post_observe` 六类钩子，分为类级别和实例级别。

### 3.2 model — 模型模块

| 类 | 说明 |
|---|---|
| `ChatModelBase` | 模型抽象基类，定义 `__call__` 异步接口，返回 `ChatResponse` 或流式 `AsyncGenerator` |
| `OpenAIChatModel` | OpenAI 兼容模型 |
| `DashScopeChatModel` | 阿里云 DashScope 模型 |
| `AnthropicChatModel` | Anthropic Claude 模型 |
| `GeminiChatModel` | Google Gemini 模型 |
| `OllamaChatModel` | Ollama 本地模型 |
| `TrinityChatModel` | Trinity 模型（微调相关） |

所有模型均通过异步接口调用，支持流式输出和 tool_choice 控制。

### 3.3 formatter — 格式化器模块

负责将 AgentScope 内部消息格式转换为各模型 API 所需的格式。每个模型提供 Chat 和 MultiAgent 两种格式化器：

- `OpenAIChatFormatter` / `OpenAIMultiAgentFormatter`
- `DashScopeChatFormatter` / `DashScopeMultiAgentFormatter`
- `AnthropicChatFormatter` / `AnthropicMultiAgentFormatter`
- `GeminiChatFormatter` / `GeminiMultiAgentFormatter`
- `OllamaChatFormatter` / `OllamaMultiAgentFormatter`
- `DeepSeekChatFormatter` / `DeepSeekMultiAgentFormatter`
- `A2AChatFormatter`

### 3.4 memory — 记忆模块

**工作记忆（Working Memory）**:

| 类 | 说明 |
|---|---|
| `MemoryBase` | 工作记忆抽象基类 |
| `InMemoryMemory` | 内存列表存储（默认） |
| `RedisMemory` | Redis 后端存储 |
| `AsyncSQLAlchemyMemory` | SQLAlchemy 异步数据库存储 |
| `TablestoreMemory` | 阿里云 TableStore 存储 |

**长期记忆（Long-term Memory）**:

| 类 | 说明 |
|---|---|
| `LongTermMemoryBase` | 长期记忆抽象基类 |
| `Mem0LongTermMemory` | 基于 Mem0 的长期记忆 |
| `ReMePersonalLongTermMemory` | ReMe 个人长期记忆 |
| `ReMeTaskLongTermMemory` | ReMe 任务长期记忆 |
| `ReMeToolLongTermMemory` | ReMe 工具长期记忆 |

### 3.5 tool — 工具模块

| 类/函数 | 说明 |
|---|---|
| `Toolkit` | 工具集管理器，支持注册/调用工具函数、MCP 工具集成、中间件、工具组 |
| `ToolResponse` | 工具调用返回值 |
| `execute_python_code` | Python 代码执行工具 |
| `execute_shell_command` | Shell 命令执行工具 |
| `view_text_file` / `write_text_file` / `insert_text_file` | 文本文件操作工具 |
| `dashscope_text_to_image` 等 | DashScope 多模态工具 |
| `openai_text_to_image` 等 | OpenAI 多模态工具 |

### 3.6 message — 消息模块

| 类 | 说明 |
|---|---|
| `Msg` | 核心消息类，携带 name、content、role、metadata |
| `TextBlock` | 文本内容块 |
| `ThinkingBlock` | 思维链内容块 |
| `ToolUseBlock` | 工具调用内容块 |
| `ToolResultBlock` | 工具返回内容块 |
| `ImageBlock` | 图片内容块 |
| `AudioBlock` | 音频内容块 |
| `VideoBlock` | 视频内容块 |
| `Base64Source` / `URLSource` | 媒体数据源 |

消息系统采用 **ContentBlock** 架构，一条 `Msg` 可包含多种类型的内容块，支持多模态消息传递。

### 3.7 pipeline — 流水线模块

| 类/函数 | 说明 |
|---|---|
| `SequentialPipeline` | 顺序执行流水线，Agent 依次处理 |
| `FanoutPipeline` | 扇出流水线，同一输入分发给多个 Agent 并行/串行处理 |
| `MsgHub` | 消息广播中心，参与者自动广播回复消息给其他参与者 |
| `ChatRoom` | 语音聊天室，基于 RealtimeAgent 实现多智能体语音对话 |
| `sequential_pipeline` | 函数式顺序流水线 |
| `fanout_pipeline` | 函数式扇出流水线 |
| `stream_printing_messages` | 流式消息打印 |

### 3.8 mcp — MCP 协议模块

| 类 | 说明 |
|---|---|
| `MCPClientBase` | MCP 客户端基类，负责 MCP 内容到 AgentScope Block 的转换 |
| `MCPToolFunction` | MCP 工具函数封装 |
| `StatefulClientBase` | 有状态 MCP 客户端基类 |
| `HttpStatefulClient` | HTTP 有状态客户端 |
| `HttpStatelessClient` | HTTP 无状态客户端 |
| `StdioStatefulClient` | Stdio 有状态客户端 |

### 3.9 rag — RAG 检索增强模块

| 类 | 说明 |
|---|---|
| `KnowledgeBase` | 知识库抽象基类，组合 EmbeddingModel + VDBStore |
| `Document` | 文档数据模型 |
| `SimpleKnowledge` | 简单知识库实现 |
| `_reader/` | 文档读取器（文本/PDF/Word/Excel/PPT） |
| `_store/` | 向量数据库存储（Qdrant/Milvus/MongoDB/OceanBase） |

### 3.10 plan — 计划模块

| 类 | 说明 |
|---|---|
| `Plan` | 计划模型，包含名称、描述、子任务列表、状态管理 |
| `SubTask` | 子任务模型，支持 todo/in_progress/done/abandoned 四种状态 |

| `tracing` | `setup_tracing`, `trace`/`trace_llm`/`trace_reply`/`trace_format`/`trace_toolkit`/`trace_embedding` | OpenTelemetry 链路追踪 |

## 5. 快速上手

```python
import agentscope

# 1. 初始化框架
agentscope.init(
    project="my-project",
    name="my-run",
    studio_url="http://localhost:5000",  # 可选，连接 Studio
)

# 2. 创建模型和格式化器
from agentscope.model import OpenAIChatModel
from agentscope.formatter import OpenAIChatFormatter

model = OpenAIChatModel(model_name="gpt-4", stream=True)
formatter = OpenAIChatFormatter()

# 3. 创建智能体
from agentscope.agent import ReActAgent
from agentscope.tool import Toolkit

toolkit = Toolkit()
# toolkit.register(my_tool_function)  # 注册工具

agent = ReActAgent(
    name="assistant",
    sys_prompt="You are a helpful assistant.",
    model=model,
    formatter=formatter,
    toolkit=toolkit,
)

# 4. 运行
msg = await agent.reply("Hello!")
```
